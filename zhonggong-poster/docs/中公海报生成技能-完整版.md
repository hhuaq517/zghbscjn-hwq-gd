# 中公教育方形推广海报生成

纯代码（Python + Pillow + pytoshop）生成方形高清推广海报，不调用 Photoshop。
本技能沉淀了广东中公设计师的交付标准、合规红线与设计系统。

## 何时使用
用户要求做中公教育的产品推广海报 / 方形宣传图 / 课件推广图，或提交「公告名词 + 课件名称 + 内容 + 拼团与单独购买定价」四要素时。

---

## 一、交付物（必须齐）
固定 3 个产物，放进**新建的独立文件夹**：
1. 方形高清 JPG —— **有二维码版**
2. 方形高清 JPG —— **无二维码版**
3. 分层可编辑 **PSD**（每个元素独立图层）

尺寸默认 `2000×2000`，JPG 用 `quality=95, subsampling=0`。
一次性脚本、临时预览图、虚拟环境等辅助文件在完成后**必须清除**，只留产物。

---

## 二、硬性红线（逐条自检，不可违反）
1. **必带中公教育 logo**（默认读 `assets/logo.png`，可用环境变量 `ZG_LOGO` 指向别处）。
2. **字体必须在白名单内**（见第四节），不得使用未明确版权的字体。
3. **必须说明课件均为电子版**（如「电子课件」标签 + 卡片内文字说明）。
4. **底部小字、低饱和度**写明课件**全称**。
5. **全图禁止出现「资料」二字**，一律用「课件」替代。
6. **规避违规广告词**（见第五节词库），用同义词替代。
7. **禁用未明确版权的素材/图形**；需要图形元素时用代码**绘制原创矢量图形**。
8. **不调用 Photoshop**，全部在代码层解决。
9. 产品文案不出现「资料」以外的政治/医疗等敏感表述；冲刺卷≠真题。

### 二维码规则
- **有二维码版**：右下留出**空白方框**（虚线描边，内含引导线），框下写「**码上获取**」；价格同时展示「X人拼团 …元」与「单独购买 …元」。
- **无二维码版**：**取消拼团表述**，价格改写「**仅售 …元**」为唯一价格，并**删除单独购买价**。
- 如材料为**真题类**，需另加小字备注「考生回忆仅供参考」（非真题不加）。

## 三、设计系统（版式与风格）

### 版式层级（自上而下）
1. 顶部：logo（白色圆角底衬托，保证深底可读）
2. 顶部右侧：**项目标签**（=`project_tag`，如「事业单位」「教师招聘」）
   - ⚠️ **不要写「XX分部/地区分部」**（属画蛇添足）；此位置永远放项目类型
3. 公告名词（居中、浅色小字）
4. ~~金色小标 kicker~~ —— **已删除，永远不要再加**（如「2026 广东 · 事业单位笔试备考」这类小字一律不要）
5. **主标题**（大号，公式：地区+项目+笔试/面试+冲刺卷/题/无+课件包）
   - **两端对齐到内容框宽度**（`title_width` = 卡片宽度 1600，字号不变，字距自动反算放宽）
   - 两行都要与下方课件内容卡片左右边缘对齐，页面更饱满
6. 副标题亮黄标（如「全真模拟 · 三套」）+「电子课件」青框标，**两个标签并排居中**
7. 课件内容卡片（白底、粗黄边、勾选列表、右上「共 N 份电子文档」、底部电子版说明）
   - **详情板块要撑满**：每行用**课件全称**（参考原始文件命名，如
     「2026海珠区事业单位招聘高校毕业生冲刺卷（一）」），名称**左对齐**、
     后缀说明（如「· 参考答案及解析」）**右对齐**，字体自适应缩放，撑满卡片不溢出
   - 底部说明文字不要太小（≥38）
8. 价格区
9. 领取说明：`购买后在中公教育 App 可下载电子文档`
10. 底部课件全称小字（低饱和）

### 美术规范
- **扁平化，禁止阴影/浮雕/发光堆叠**（此前教训：阴影过多导致画面杂乱、图层不协调）。
- **活力撞色**（低饱和太"闷"也不好，用有活力的强对比撞色）：
  宝蓝底 + 珊瑚橙 + 亮黄 + 电光青，四种颜色互相撞击但有主次。
  参考值：底 `#122060→#224AB2`、白 `#FFF`、浅 `#C6D6FF`、次要 `#9CAEE2`、
  强调色（珊瑚橙）`#FA6C4A`、亮黄 `#FFCD3D`、青 `#3DD6E8`、卡片文字墨蓝 `#1A245C`。
  ⚠️ **不要用纯正红 `#FF0000/#FF3B3B`**——在宝蓝底上太突兀刺眼，用珊瑚橙过渡。
- **主次分明**：核心标题/价格/冲刺卷关键字用珊瑚橙，副标题用亮黄底+墨蓝字，辅助标签用青。
- **地域/项目元素**：每个新产品按地区特性提取元素，用代码绘制原创矢量（如广州塔线稿 + 珠江水纹 + 琶洲几何）。**每次风格必须有区别**，不要千篇一律。
- 图形元素透明度控制在 0.1–0.25 之间，做背景纹理，不与前景争抢。

### 字体规范（只可用下列已安装字体）
| 用途 | 字体 | 文件 |
|---|---|---|
| **大标题（稳重，首选）** | 方正兰亭粗黑 | `FZLTCHJW.TTF` |
| 大标题备选（加粗宋体） | 方正特雅宋 | `FZTYSJW.ttf` |
| 大标题备选（更重） | 方正兰亭特黑 / 方正粗谭黑 | `FZLTTHJW.TTF` / `FZCTHJW.TTF` |
| 次级/小标题 | 方正兰亭粗黑 | `FZLTCHJW.TTF` |
| 正文 | 方正兰亭黑 | `FZLTHJW.TTF` |
| 备选黑/标题 | 站酷高端黑 / 站酷酷黑 / 庞门正道标题体 | `站酷高端黑修订版1.13.ttf` / `站酷酷黑.ttf` / `庞门正道标题体2.0增强版.ttf` |

> **大标题必须稳重**：用方正兰亭**粗黑**（B 字重）。
> ⚠️ **不要用特黑/超粗**——笔画会粘连，字口糊成一团；太粗反而显廉价。

## 四、工作流
1. **收集四要素**：公告名词 / 课件名称 / 内容截图或文字 / 拼团价与单独价。
2. **澄清**：有疑问先反问（尺寸、二维码处理、大标题文案、地域元素方向、真题与否、底部全称）；把把握提到 95% 再动手。
3. **读公告**（若给链接）：提取报名时间、笔试时间/内容、招聘人数，作为海报可用的信息点。
4. **改配置**：编辑 `poster.py` 顶部 `CONFIG`（或用 `--config cfg.json` 覆盖）。
5. **生成**：`python3 poster.py --psd`。
6. **自检**：运行输出会打印文案合规检查；再用 `get_document_image`/读图核对版式。
7. **核对产物**：2 JPG + 1 PSD，目录只留产物；**删除脚本临时件与虚拟环境**。
8. 若用户提出修改，回到第 4 步改 CONFIG 重生成。

---

## 五、文案合规词库（自动检查 + 人工复核）
**禁用（命中即改）**：资料、真题、押题、上岸、保过、包过、协议班、绝密、内部、命题、
命中、预测、必过、保分、官方指定、第一、最好/最佳/最强、100%、百分百、泄题、原题。

**合规替代**：资料→课件；真题→历年试题；押题→冲刺卷/模拟卷；上岸→成功入围/考入。

## 六、poster.py 使用
路径：本技能目录下的 `poster.py`（与本文件同级）

- 依赖：`pillow numpy pytoshop psd-tools six`（见 `requirements.txt`）
- 安装：`pip install -r requirements.txt`
- 首次在临时目录建虚拟环境安装即可，完成后清理。
- **路径解析**：`out_dir` / `logo_path` 默认相对脚本目录（`./out`、`./assets/logo.png`），
  可用环境变量 `ZG_OUT_DIR` / `ZG_LOGO` / `ZG_FONT_DIR` 覆盖，换台电脑无需改代码。
- `CONFIG` 字段：
  `out_dir, base_name, size, logo_path, project_tag, notice, title_main,
   title_sub[[文本,"w|r"]], title_main_size, title_sub_size, title_width,
   subtitle, badge, content_title, content_meta, content_rows[[全称,后缀]],
   content_note, price_group, price_value, price_single, only_price, only_sub,
   claim, footer, motif, palette{...}`
- **无 kicker 字段**（已永久移除）。
- `motif`：`canton_tower`（广州）/ `waves` / `grid`，按项目所在地替换为对应原创元素。
- `palette`：整套撞色，可整体替换以适配不同项目（如教师招聘用绿黄撞色）。
- 输出：`{base_name}_有二维码.jpg`、`{base_name}_无二维码.jpg`、`{base_name}.psd`（14 图层）。

def C(k):
    return PAL[k]


def F(name, size):

def new_canvas():
    return Image.new("RGBA", (S, S), (0, 0, 0, 0))


def vgrad(c1, c2):
    ramp = np.linspace(0, 1, S).reshape(S, 1, 1)
    a = (np.array(c1, float).reshape(1, 1, 3) * (1 - ramp) +
         np.array(c2, float).reshape(1, 1, 3) * ramp).astype(np.uint8)
    return Image.fromarray(np.repeat(a, S, axis=1), "RGB").convert("RGBA")


def glow(cx, cy, r, color, strength):
    yy, xx = np.mgrid[0:S, 0:S]
    d = np.sqrt((xx - cx) ** 2 + (yy - cy) ** 2) / r
    m = np.clip(1 - d, 0, 1) ** 2 * strength
    layer = np.zeros((S, S, 4), np.uint8)
    for i in range(3):
        layer[..., i] = color[i]
    layer[..., 3] = (m * 255).astype(np.uint8)
    return Image.fromarray(layer, "RGBA")


def text_img(text, font, fill, sw=0, sfill=None):
    d = ImageDraw.Draw(Image.new("RGBA", (10, 10)))
    b = d.textbbox((0, 0), text, font=font, stroke_width=sw)
    pad = 6
    out = Image.new("RGBA", (b[2] - b[0] + pad * 2 + sw * 2,
                             b[3] - b[1] + pad * 2 + sw * 2), (0, 0, 0, 0))
    ImageDraw.Draw(out).text((pad - b[0], pad - b[1]), text, font=font, fill=fill,
                             stroke_width=sw, stroke_fill=sfill)
    return out


def put(layer, im, cx, cy):
    layer.alpha_composite(im, (int(cx - im.size[0] / 2), int(cy - im.size[1] / 2)))


def tracked_segs(layer, segs, font, cx, cy, track):
    """segs: [(text, fill, stroke_fill)] 带字距，整行居中，返回总宽"""
    chars = [(ch, fill, sf) for (t, fill, sf) in segs for ch in t]
    ws = [font.getlength(ch) for ch, _, _ in chars]
    total = sum(ws) + track * (len(chars) - 1)
    x = cx - total / 2
    for (ch, fill, sf), w in zip(chars, ws):
        im = text_img(ch, font, fill, 3, sf)
        layer.alpha_composite(im, (int(x), int(cy - im.size[1] / 2)))
        x += w + track
    return total


def fit_track(text, font, target):
    """按目标宽度反算字距，使该行两端对齐到 target 宽度"""
    ws = [font.getlength(ch) for ch in text]
    if len(ws) < 2:
        return 0
    return (target - sum(ws)) / (len(ws) - 1)

    bg.alpha_composite(glow(1500, 700, 800, (90, 140, 255), 0.20))
    return bg

    if motif == "canton_tower":
        cx, top, bot = 1660, 300, 1580
        wmin, tw, ka, kb = 30, 0.60, 2.15, 1.55

        def half(t):
            return (1.95 * wmin * math.cosh(ka * (tw - t)) if t <= tw
                    else 1.55 * wmin * math.cosh(kb * (t - tw)))
        n = 90
        left, right = [], []
        for i in range(n + 1):
            t = i / n
            y = top + (bot - top) * t
            w = half(t)

        dr.line(left, fill=line_c + (95,), width=3)

        for i in range(0, n, 5):
            t = i / n
            y = top + (bot - top) * t
            w = half(t)
            dr.line([(cx - w, y), (cx + w, y)], fill=line_c + (48,), width=2)
        dr.line([(cx, top), (cx, 158)], fill=line_c + (95,), width=4)

def dash_rect(d, box, radius, color, width, dash, gap):
    x0, y0, x1, y1 = box
    for a, b in [((x0 + radius, y0), (x1 - radius, y0)), ((x0 + radius, y1), (x1 - radius, y1)),
                 ((x0, y0 + radius), (x0, y1 - radius)), ((x1, y0 + radius), (x1, y1 - radius))]:
        length = math.hypot(b[0] - a[0], b[1] - a[1])
        ux, uy = (b[0] - a[0]) / length, (b[1] - a[1]) / length
        t = 0
        while t < length:
            e = min(t + dash, length)
            d.line([(a[0] + ux * t, a[1] + uy * t), (a[0] + ux * e, a[1] + uy * e)],
                   fill=color, width=width)
            t = e + gap
    for cxx, cyy, s in [(x0 + radius, y0 + radius, 90), (x1 - radius, y0 + radius, 0),
                        (x0 + radius, y1 - radius, 180), (x1 - radius, y1 - radius, 270)]:
        d.arc([cxx - radius, cyy - radius, cxx + radius, cyy + radius], s, s + 90,
              fill=color, width=width)

def check_copy(cfg):
    texts = []
    def walk(v):
        if isinstance(v, str):
            texts.append(v)
        elif isinstance(v, (list, tuple)):
            for x in v:
                walk(x)
        elif isinstance(v, dict):
            for x in v.values():
                walk(x)
    walk(cfg)
    hits = {}
    for w in BANNED_WORDS:
        for t in texts:
            if w in t:
                hits.setdefault(w, []).append(t)
    return hits

def flatten(layers):

def save_psd(layers, path):
    from pytoshop.user import nested_layers as nl
    from pytoshop import enums, image_data
    psd_layers = []
    for name, im in layers:
        a = np.array(im.convert("RGBA"))
        psd_layers.append(nl.Image(name=name, visible=True, opacity=255, group_id=0,
                                   blend_mode=enums.BlendMode.normal, top=0, left=0,
                                   channels={0: a[..., 0], 1: a[..., 1], 2: a[..., 2], -1: a[..., 3]}))
    psd = nl.nested_layers_to_psd(psd_layers, color_mode=enums.ColorMode.rgb,
                                  size=(S, S), compression=enums.Compression.zip)
    arr = np.array(flatten(layers).convert("RGB"))
    psd.image_data = image_data.ImageData(
        channels=np.stack([arr[..., 0], arr[..., 1], arr[..., 2]]),
        compression=enums.Compression.zip)
    with open(path, "wb") as f:
        psd.write(f)
