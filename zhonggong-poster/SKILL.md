# 中公教育方形推广海报生成

纯代码（Python + Pillow + pytoshop）生成方形高清推广海报，不调用 Photoshop。
本技能沉淀了广东中公设计师的交付标准、合规红线与设计系统。

## 何时使用
用户要求做中公教育的产品推广海报 / 方形宣传图 / 课件推广图，或提交「公告名词 + 课件名称 + 内容 + 拼团与单独购买定价」四要素时。

---

## 一、交付物（必须齐）
固定 3 个产物，放进**新建的独立文件夹**：
1. 方形高清 JPG —— **有二维码版**
2. 方形高清 JPG —— **无二维码版**
3. 分层可编辑 **PSD**（每个元素独立图层）

尺寸默认 `2000×2000`，JPG 用 `quality=95, subsampling=0`。
一次性脚本、临时预览图、虚拟环境等辅助文件在完成后**必须清除**，只留产物。

---

## 二、硬性红线（逐条自检，不可违反）
1. **必带中公教育 logo**（包内 `assets/zhonggong-logo.png`，`CONFIG.logo_path` 已默认指向它，无需修改）。
2. **字体必须在白名单内**（见第四节），不得使用未明确版权的字体。
3. **必须说明课件均为电子版**（如「电子课件」标签 + 卡片内文字说明）。
4. **底部小字、低饱和度**写明课件**全称**。
5. **全图禁止出现「资料」二字**，一律用「课件」替代。
6. **规避违规广告词**（见第五节词库），用同义词替代。
7. **禁用未明确版权的素材/图形**；需要图形元素时用代码**绘制原创矢量图形**。
8. **不调用 Photoshop**，全部在代码层解决。
9. 产品文案不出现「资料」以外的政治/医疗等敏感表述；冲刺卷≠真题。

### 二维码规则
- **有二维码版**：右下留出**空白方框**（虚线描边，内含引导线），框下写「**码上获取**」；价格同时展示「X人拼团 …元」与「单独购买 …元」。
- **无二维码版**：**取消拼团表述**，价格改写「**仅售 …元**」为唯一价格，并**删除单独购买价**。
- 如材料为**真题类**，需另加小字备注「考生回忆仅供参考」（非真题不加）。

### PSD 编码规则（务必遵守，否则 PSD 打不开）
- **合成图（预览图）必须用 RLE 压缩**（`Compression.rle`），**严禁用 ZIP**。
  ZIP 压缩合成图的 PSD，macOS 预览（ImageIO）与 Photoshop 都会判定「文件打不开」。
- pytoshop 的 RLE 依赖未编译的 C 扩展 `packbits`；缺失时用**纯 Python PackBits 兜底**
  （`poster.py` 的 `_ensure_packbits()` 已内置，`save_psd()` 会自动调用，无需手工处理）。
- 图层数据可继续用 ZIP（体积小、Photoshop 支持），只有**合成图**必须 RLE。
- ⚠️ **psd-tools 能读 ≠ Photoshop 能开**。交付前必须用 `sips -g pixelWidth xxx.psd`
  验证能读出尺寸；读出 `<nil>` 即为打不开，必须修复后重出。

### PSD 图层顺序规则（务必遵守，否则背景会盖在最上面）
- **图层栈必须「背景在最底层」**：自下而上固定为
  `背景-渐变 → 背景-地域元素 → 背景-水纹 → 顶部细线 → logo → 项目标签 → 公告名词 → 主标题 → 电子课件标签 → 副标题 → 课件内容卡片 → 价格区 → 领取说明 → 底部课件全称`
  （总图在「课件内容卡片」前多一层「专项标签列」）。
  打开 PSD 时 Photoshop 图层面板**从上往下**应看到：底部课件全称 … 背景-渐变（背景在最后）。
- `save_psd(layers, path)` 的入参 `layers` 是 **【自下而上】** 顺序（最底层在最前），
  函数内会用**稳定排序**把「背景*」压到最前 = 最底层。
- ⚠️ **`save_psd()` 里绝对不能对列表再做 `reversed()`**：`pytoshop.nested_layers_to_psd`
  内部已对图层列表执行过一次 `[::-1]`，再反转一次会让**整摞图层上下颠倒、背景被顶到最上面**。
  （2026-09-30 事故根因，已修复，勿回退。）
- 交付前必须用 psd-tools 断言：`[l.name for l in PSDImage.open(p)][-1].startswith("背景")`
  且 `[0]` 不是「背景*」；不满足即不合格，必须重出。

## 三、设计系统（版式与风格）

### 版式层级（自上而下）
1. 顶部：logo（白色圆角底衬托，保证深底可读）
2. 顶部右侧：**项目标签**（=`project_tag`，如「事业单位」「教师招聘」）
   - ⚠️ **不要写「XX分部/地区分部」**（属画蛇添足）；此位置永远放项目类型
3. 公告名词（居中、浅色小字）
4. ~~金色小标 kicker~~ —— **已删除，永远不要再加**（如「2026 广东 · 事业单位笔试备考」这类小字一律不要）
5. **主标题**（大号，公式：地区+项目+笔试/面试+冲刺卷/题/无+课件包）
   - **两端对齐到内容框宽度**（`title_width` = 卡片宽度 1600，字号不变，字距自动反算放宽）
   - 两行都要与下方课件内容卡片左右边缘对齐，页面更饱满
6. 副标题亮黄标（如「全真模拟 · 三套」）+「电子课件」青框标，**两个标签并排居中**
7. 课件内容卡片（白底、粗黄边、勾选列表、右上「共 N 份电子文档」、底部电子版说明）
   - **详情板块要撑满**：每行用**课件全称**（参考原始文件命名，如
     「2026海珠区事业单位招聘高校毕业生冲刺卷（一）」），名称**左对齐**、
     后缀说明（如「· 参考答案及解析」）**右对齐**，字体自适应缩放，撑满卡片不溢出
   - 底部说明文字不要太小（≥38）
8. 价格区
9. 领取说明：`购买后在中公教育 App 可下载电子文档`
10. 底部课件全称小字（低饱和）

### 配色与版式轮换规则（底层规则 · 勿回退）
**每出一张新海报，配色必须换、版式也必须换**；禁止与最近 4 张中的任何一张重复。

- 配色从 `styles.PALETTES` 取（10 套：宝蓝珊瑚 / 墨绿柠黄 / 绛紫蜜橙 / 深海电青 /
  赤陶沙金 / 松石柠檬 / 梅子紫玫 / 夜棕薄荷 / 藏青鎏金 / 赤金鸿运），每套含
  `bg_top/bg_bot/white/light/mute/track/ink/red/yellow/cyan` 十个基础键，直接替换整套；
  「大气庄重」两套（藏青鎏金 / 赤金鸿运）另带可选扩展键
  `cardline`（卡片描边）/ `stroke_w`（白字描边）/ `stroke_r`（强调字描边）/ `glow3`（第三层光晕）。
  ⚠️ 这两套里 `red` 键放的是**鎏金强调色**、`cyan` 键放**香槟金**（不是真红/真青），
  因为底色本身已是深色，强调色必须用金才够大气。
- 版式从 `styles.LAYOUTS` 取（7 套：居中宽卡 / 通栏高卡 / 窄卡阔景 / 左码右价 / 居价宽卡 /
  鎏金通栏 / 赤金阔幕），
  每套会改：标题字号与 `title_width`、公告与标题的纵向节奏、`content_box` 卡片几何、
  `price_align` 价格对齐（left/center/right）、`qr_box` 二维码位置（左下或右下）。
- **轮换状态**存在 `assets/rotation.json`（记录 palette / layout 使用历史），
  `poster.main()` 会自动挑「最近 4 次未用过」的一套并在出图成功后写回历史。
- 需要指定时用 `palette_name` / `layout_name`（仍须避免与上一张重复）；
  完全自定义时用 `no_rotate: true` 直接给 `palette`。
- 小鹿lulu 的形象与落点 seed 已绑定「配色+版式」，换配色/版式时小鹿也会变，避免雷同。
- 交付前自检：确认本次配色与版式都与上一张不同，且 `rotation.json` 已记录本次组合。

### 美术规范
- **扁平化，禁止阴影/浮雕/发光堆叠**（此前教训：阴影过多导致画面杂乱、图层不协调）。
- **活力撞色，且每张必须换一套**（低饱和太"闷"也不好，用有活力的强对比撞色）：
  底色 + 珊瑚橙/暖橙 + 亮黄 + 电光青，四种颜色互相撞击但有主次。
  具体配色一律从 `styles.PALETTES` 轮换取用，见上节「配色与版式轮换规则」。
  参考值（宝蓝珊瑚那套）：底 `#122060→#224AB2`、白 `#FFF`、浅 `#C6D6FF`、次要 `#9CAEE2`、
  强调色 `#FA6C4A`、亮黄 `#FFCD3D`、青 `#3DD6E8`、卡片文字墨蓝 `#1A245C`。
  ⚠️ **不要用纯正红 `#FF0000/#FF3B3B`**——在任何底色上都太突兀刺眼，用暖橙过渡。
- **主次分明**：核心标题/价格/冲刺卷关键字用珊瑚橙，副标题用亮黄底+墨蓝字，辅助标签用青。
- **地域/项目元素**：每个新产品按地区特性提取元素，用代码绘制原创矢量（如广州塔线稿 + 珠江水纹 + 琶洲几何）。**每次风格必须有区别**，不要千篇一律。
- 图形元素透明度控制在 0.1–0.25 之间，做背景纹理，不与前景争抢。

### 字体规范（只可用下列已安装字体）
| 用途 | 字体 | 文件 |
|---|---|---|
| **大标题（稳重，首选）** | 方正兰亭粗黑 | `FZLTCHJW.TTF` |
| 大标题备选（加粗宋体） | 方正特雅宋 | `FZTYSJW.ttf` |
| 大标题备选（更重） | 方正兰亭特黑 / 方正粗谭黑 | `FZLTTHJW.TTF` / `FZCTHJW.TTF` |
| 次级/小标题 | 方正兰亭粗黑 | `FZLTCHJW.TTF` |
| 正文 | 方正兰亭黑 | `FZLTHJW.TTF` |
| 备选黑/标题 | 站酷高端黑 / 站酷酷黑 / 庞门正道标题体 | `站酷高端黑修订版1.13.ttf` / `站酷酷黑.ttf` / `庞门正道标题体2.0增强版.ttf` |

> **大标题必须稳重**：用方正兰亭**粗黑**（B 字重）。
> ⚠️ **不要用特黑/超粗**——笔画会粘连，字口糊成一团；太粗反而显廉价。

### 小鹿lulu 形象规范（每张必带 · 形象与落点随机）
海报**必须带一只小鹿lulu**，让画面更活泼。由 `xiaolu.py` 实现，`poster.py` 默认自动调用。

- **形象按考试类型匹配**（`xiaolu.POSE_LIB` 的 `types`）：

  | 考试类型 | 可用形象 |
  |---|---|
  | 备考 | 1 坐书堆读书 / 2 眼镜学霸 / 5 挥手 / 12 披风欢呼 / 13 书桌写字 / 14 斗篷冲刺 / 21 举奖杯 / 24 拿文件夹 |
  | 公安军警 | 22 军装敬礼 / 21 举奖杯 / 5 挥手 |
  | 基层乡村 | 15 草帽麦穗 / 21 举奖杯 / 5 挥手 |
  | 面试 | 23 奔跑欢笑 / 4 坐姿微笑 / 24 拿文件夹 / 5 挥手 |
  | 金融国企 | 24 拿文件夹 / 2 眼镜学霸 / 21 举奖杯 / 5 挥手 |
  | 活动福利 | 11 吃西瓜 |
  | 通用 | 4 / 5 / 12 / 23 |

  同一张图在该类型池里**随机取一个**；一批多张时把已用 id 传给 `exclude`，避免重样。

- **落点必须零遮挡**：把形象 alpha 足迹与「除背景层外所有图层」的占用图求交，
  **零重叠**才算合法 → 绝不压标题 / 内容卡 / 价格 / 二维码。
- **落点区**（2000×2000 实测留白带，`xiaolu.REGIONS`）：左下角、右下角（优先，65% 概率）、
  左侧中部、右侧中部；顶部横带仅作兜底。形象高 240–430（兜底 190–246），
  在最贴合贴边意图的前 25% 候选里随机，避免每张都一模一样。
  ⚠️ 左右侧腰区的 **y 下限是 900**——标题带（y≈420–800）一律不放，否则小鹿会紧贴主标题显拥挤
  （2026-10-08 修正，勿回退）。
- **左右交替**：一批多张时给 `xiaolu.add(..., prefer="left"/"right")` 左右轮流，
  避免整批小鹿全挤在右下角；该侧无零重叠落点时会自动回落到另一侧。
- **图层位置**：插在「背景三件套」**之上**、其余内容**之下**，图层名固定 `小鹿lulu形象`
  （保证 PSD 里背景仍垫底）。
- **两版一致**：有码 / 无码两版**共用**同一形象与落点（按两版占用图并集求解）。
- 素材：`assets/xiaolu/lulu*.png`（已裁边、按高 1000 归一化）。新增形象时把 PNG 放进该目录，
  并在 `POSE_LIB` 登记 `id / file / scene / types`。

## 四、工作流
1. **收集四要素**：公告名词 / 课件名称 / 内容截图或文字 / 拼团价与单独价。
2. **澄清**：有疑问先反问（尺寸、二维码处理、大标题文案、地域元素方向、真题与否、底部全称）；把把握提到 95% 再动手。
3. **读公告**（若给链接）：提取报名时间、笔试时间/内容、招聘人数，作为海报可用的信息点。
4. **改配置**：编辑 `poster.py` 顶部 `CONFIG`（或用 `--config cfg.json` 覆盖），
   别忘了按项目填 `xiaolu.exam_type`（决定小鹿形象池）。
5. **生成**：`python3 poster.py --psd`。
6. **自检**：运行输出会打印文案合规检查；再用 `get_document_image`/读图核对版式。
7. **核对产物**：2 JPG + 1 PSD，目录只留产物；**删除脚本临时件与虚拟环境**。
8. 若用户提出修改，回到第 4 步改 CONFIG 重生成。

## 五、文案合规词库（自动检查 + 人工复核）
**禁用（命中即改）**：资料、真题、押题、上岸、保过、包过、协议班、绝密、内部、命题、
命中、预测、必过、保分、官方指定、第一、最好/最佳/最强、100%、百分百、泄题、原题。

**合规替代**：资料→课件；真题→历年试题；押题→冲刺卷/模拟卷；上岸→成功入围/考入。

## 六、poster.py 使用
路径：本技能目录下的 `poster.py`（与本文件同级），同目录另有 `styles.py`（配色/版式库）
与 `xiaolu.py`（小鹿lulu 落位引擎），三者需放在一起。

- 依赖：`pillow numpy pytoshop psd-tools six`（见 `requirements.txt`）
- 安装：`pip install -r requirements.txt`
- 首次在临时目录建虚拟环境安装即可，完成后清理。
- **路径解析**：`logo_path` 相对脚本目录（`assets/zhonggong-logo.png`），
  `out_dir` 默认 `<当前工作目录>/海报成品`；可用环境变量
  `ZG_OUT_DIR` / `ZG_LOGO` / `ZG_FONT_DIR` 覆盖，换台电脑无需改代码。
- `CONFIG` 字段：
  `out_dir, base_name, size, logo_path, project_tag, notice, title_main,
   title_sub[[文本,"w|r"]], title_main_size, title_sub_size, title_width,
   subtitle, badge, content_title, content_meta, content_rows[[全称,后缀]],
   content_note, price_group, price_value, price_single, only_price, only_sub,
   claim, footer, motif, palette{...}, xiaolu{enable, exam_type, seed}`
- **配色 / 版式（轮换，见上「配色与版式轮换规则」）**：
  `palette_name`、`layout_name`（指定本次用哪套；不填自动轮换）、`no_rotate`（true 则不轮换，
  直接用 `palette`）、`price_align`（left/center/right）、`price_margin`（价格左右对齐的边距）。
- **版式可选字段**（不填即沿用原版式，向后兼容）：
  `notice_size`（默认 42）、`notice_fill`（true 时公告名词按 `title_width` 反算字距，
  与大标题同宽）、`notice_y`（296）、`title_main_y`（486）、`title_sub_y`（730）、
  `subtitle_y`（878）、`content_box`（`[200,990,1800,1490]`）、
  `price_dy`（价格区整体下移量，0）、`qr_box`（`[x,y,size]`，默认 `[1448,1524+price_dy,268]`）。
  **课件行数自适应**：`L_content` 按 `len(content_rows)` 自动分行、自动缩字号（22–46），
  行数多时用 `content_box` 把卡片加高即可（如 8 行用 `[200,930,1800,1552]` + `subtitle_y=818`）。
- **无 kicker 字段**（已永久移除）。
- `motif`：`canton_tower`（广州）/ `waves` / `grid` / `huizhou`（惠州·合江楼三层飞檐楼阁+东江拱桥），
  按项目所在地替换为对应原创元素。
- `palette`：整套撞色，可整体替换以适配不同项目（如教师招聘用绿黄撞色）。
- `xiaolu`：**默认开启**。`exam_type` 按项目填（备考/公安军警/基层乡村/面试/金融国企/活动福利），
  决定小鹿形象池；`seed` 不填则按 `base_name` 自动定种（可复现）。关掉用 `{"enable": false}`。
- 输出：`{base_name}_有二维码.jpg`、`{base_name}_无二维码.jpg`、`{base_name}.psd`（15 图层，含小鹿lulu形象）。
- `save_psd()`：**图层用 ZIP、合成图用 RLE**，并自动补 PackBits 兜底——保证 PSD 能被
