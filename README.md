# 中公海报生成器 · zhonggong-poster

> 一段配置 → 两张 **2000 × 2000** 方形高清海报（有码版 / 无码版）+ 一份 **15 图层**可编辑 PSD。
> 全程 Python 出图，**不调用 Photoshop**，不依赖任何外部素材。
> **10 套配色 × 7 套版式自动轮换**，每张海报都带一只随机落位的小鹿lulu。

`v1.1` · 广东中公教育

---

## 产出长什么样

| 产物 | 内容 |
|---|---|
| `XXX_有二维码.jpg` | 二维码占位框（虚线描边 + 引导线），框下写「码上获取」；价格同时展示「X人拼团 …元」与「单独购买 …元」 |
| `XXX_无二维码.jpg` | 取消拼团表述，价格改写「**仅售 …元**」为唯一价格，并删除单独购买价 |
| `XXX.psd` | 分层可编辑，15 个独立图层，改字改色不用重跑脚本 |

固定方形 2000×2000，JPG 用 `quality=95, subsampling=0`，印刷与线上投放都够用。

## 特性

- **一次跑出三件套** —— 有码 / 无码 / PSD 同源生成，三份版式绝对一致，不会出现两版对不齐。
- **配色 × 版式自动轮换** —— 10 套配色 × 7 套版式，每次自动挑「最近 4 次未用过」的组合，**保证相邻海报不撞色不撞版**。轮换历史持久化，换人接着用也不会断。
- **小鹿lulu 形象系统** —— 14 张形象素材，按考试类型匹配，在留白安全区随机落位。**落点零遮挡**（把形象 alpha 足迹与除背景外所有图层求交，零重叠才合法），绝不压标题 / 内容卡 / 价格 / 二维码。
- **6 种地域元素** —— 广州塔线稿 / 珠江水纹 / 网格 / 惠州合江楼 / 珠海日月贝 / 国考鎏金光芒，全部代码绘制原创矢量，版权干净。
- **文案合规自检** —— 内置 24 条违规广告词黑名单（含「资料」「真题」「押题」「上岸」等），运行时自动扫描全配置并打印命中项，出图前就拦下来。
- **字体白名单硬约束** —— 只从授权字体库按文件名加载，绝不回落到系统字体（PingFang / 微软雅黑一律禁止）。
- **PSD 双压缩策略** —— 图层用 ZIP（体积小、PS 支持），**合成图必须用 RLE**（ZIP 压缩的合成图 macOS 预览与 Photoshop 都打不开）。pytoshop 的 RLE 依赖未编译 C 扩展，已内置纯 Python PackBits 兜底。
- **标题自动两端对齐** —— 给定 `title_width`，程序反算字距让主标题撑满内容框宽度，字号不变。
- **详情行自适应缩放** —— 课件全称 + 后缀说明一行塞不下时自动缩字号（22–46），行数多时自动分行，撑满卡片不溢出。
- **专项标签列** —— 总图可用 `tabs` 在卡片左侧生成一列专项彩色胶囊（勾选图标 + 专项名）。
- **路径零硬编码** —— 输出目录、logo、字体目录全部相对脚本解析，并支持环境变量覆盖，换台电脑直接跑。


## 快速开始

### 一、出图

**方式一：把素材丢给 AI（推荐）**

把「公告名词 + 课件名称 + 内容 + 拼团价与单独价」四要素发过去，说一句「出海报」。
AI 会改配置 → 出图 → 跑合规自检 → 读图核对版式 → 交 2 JPG + 1 PSD。

**方式二：自己跑**

1. 打开 `poster.py`，改顶部 `CONFIG`（每个字段都有中文注释）：

```python
CONFIG = {
    "base_name": "海珠事编笔试冲刺卷课件包",      # 决定三个产物的文件名
    "project_tag": "事业单位",                    # 右上角项目标签
    "notice": "2026年广州市海珠区事业单位公开招聘高校毕业生公告",   # 公告名词
    "title_main": "海珠事编",
    "title_sub": [["笔试", "w"], ["冲刺卷", "r"]],  # w=白 r=强调色
    "content_rows": [
        ["2026海珠区事业单位招聘高校毕业生冲刺卷（一）", "· 参考答案及解析"],
        ...
    ],
    "xiaolu": {"enable": True, "exam_type": "备考"},
    ...
}
```

2. 跑：

```bash
cd zhonggong-poster
python3 poster.py            # 只出 2 张 JPG
python3 poster.py --psd      # 额外出分层 PSD（推荐）
```

3. 想不改代码、只换一份配置？另存一个 JSON，用 `--config` 覆盖：

```bash
python3 poster.py --psd --config 我的海报.json
```

JSON 里只需写要覆盖的字段（浅合并），其余仍走 `CONFIG` 默认值。

### 二、产物落哪

默认输出到 `<当前工作目录>/海报成品/`。想换地方：

```bash
ZG_OUT_DIR="/Users/你/海报成品" python3 poster.py --psd
```

Windows 用 `set ZG_OUT_DIR=...`，PowerShell 用 `$env:ZG_OUT_DIR="..."`。

程序还会往系统临时目录写两张 1000×1000 的预览缩略图（`zg_preview_*.jpg`），方便快速目检，不影响成品目录。

### 三、轮换怎么用

**什么都不用做。** `poster.main()` 会自动从「最近 4 次未用过」的组合里挑一套配色 + 一套版式，
出图成功后把本次组合写回 `assets/rotation.json`。跑完会打印一行：

```
配色：赤金鸿运 ｜ 版式：赤金阔幕
```

想指定就用 `palette_name` / `layout_name`；想完全自定义就 `no_rotate: true` 并直接给 `palette`。

## PSD 两条硬规则

**1. 合成图必须 RLE 压缩，不能 ZIP。** ZIP 压缩的合成图不被 macOS 预览（ImageIO）
与 Photoshop 支持，会被判定「文件打不开」。图层数据仍用 ZIP。pytoshop 的 RLE 依赖
未编译的 C 扩展 `packbits`，`_ensure_packbits()` 已内置纯 Python 兜底，无需手工处理。

> ⚠️ **psd-tools 能读 ≠ Photoshop 能开。** 交付前必须用
> `sips -g pixelWidth xxx.psd` 验证能读出尺寸；读出 `<nil>` 即为打不开。

**2. 图层栈必须背景垫底。** 自下而上固定为：
`背景-渐变 → 背景-地域元素 → 背景-水纹 → 顶部细线 → logo → 项目标签 → 公告名词 →
主标题 → 电子课件标签 → 副标题 → 课件内容卡片 → 价格区 → 领取说明 → 底部课件全称`
（总图在「课件内容卡片」前多一层「专项标签列」，小鹿插在背景三件套之上、其余内容之下）。

> ⚠️ `save_psd()` 里**绝对不能对图层列表再做 `reversed()`**：
> `pytoshop.nested_layers_to_psd` 内部已执行过一次 `[::-1]`，再反转一次会让
> 整摞图层上下颠倒、背景被顶到最上面。（2026-09-30 事故根因，已修复，勿回退。）

## 九条红线（逐条自检，不可违反）

1. **必带中公教育 logo**。
2. **字体必须在白名单内**，不得使用版权不明的字体。
3. **必须说明课件均为电子版**（「电子课件」标签 + 卡片内文字说明，两处都要）。
4. **底部小字、低饱和度**写明课件**全称**。
5. **全图禁止出现「资料」二字**，一律用「课件」替代。
6. **规避违规广告词**（见下），用同义词替代。
7. **禁用版权不明素材**；需要图形元素时用代码绘制原创矢量。
8. **不调用 Photoshop**，全部在代码层解决。
9. 文案不出现政治 / 医疗等敏感表述；**冲刺卷 ≠ 真题**。

### 违规广告词黑名单

```
资料、真题、押题、上岸、保过、包过、协议班、绝密、内部、命题、
命中、预测、必过、保分、官方指定、第一、最好、最佳、最强、
100%、百分百、泄题、原题、保过班
```

**合规替代**：资料→课件；真题→历年试题；押题→冲刺卷/模拟卷；上岸→成功入围/考入。

脚本每次运行都会扫一遍全配置并打印结果，命中会明确列出是哪个字段的哪句话。

## 设计系统要点

- **扁平化**，禁止阴影 / 浮雕 / 发光堆叠。画面乱、图层不协调基本都是阴影惹的。
- **活力撞色，且每张必须换一套**。核心标题 / 价格 / 冲刺卷关键字用强调色，
  副标题用亮黄底 + 墨蓝字，辅助标签用青。
  ⚠️ **不要用纯正红 `#FF0000` / `#FF3B3B`** —— 在任何底色上都太突兀刺眼，用暖橙过渡。
- **版式层级（自上而下）**：logo → 项目标签（右上）→ 公告名词 → 主标题两行 →
  副标题 + 电子课件标签（并排居中）→ 课件内容卡片 → 价格区 → 领取说明 → 底部全称小字。
- **大标题必须稳重**：用方正兰亭**粗黑**（B 字重）。不要用特黑 / 超粗，笔画会粘连、字口糊成一团，太粗反而显廉价。
- **地域元素**按项目所在地替换，透明度控制在 0.1–0.25 之间做背景纹理，不与前景争抢。**每次风格必须有区别**。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `FileNotFoundError: assets/zhonggong-logo.png` | 缺 logo。把图放回 `assets/`，或设 `ZG_LOGO` |
| `ModuleNotFoundError: No module named 'xiaolu'` | 三个 `.py` 没放在同一目录，或没在技能目录下运行 |
| 报错找不到字体 | 装授权字体库到 `~/Library/Fonts`，或设 `ZG_FONT_DIR` |
| 打印「!! 小鹿未找到留白落点，已跳过」 | 卡片 / 价格占满了留白区。调小 `content_box` 或缩小形象高度上限 |
| 连着两张撞了配色 | `assets/rotation.json` 被删或不可写；确认该文件存在且可写 |
| PSD 在 macOS 预览打不开 | 合成图被 ZIP 压缩了。确认走的是本仓库的 `save_psd()`（内部强制 RLE） |
| PSD 打开后背景在最上面 | 图层顺序反了。`save_psd()` 里不能加 `reversed()` |
| 卡片说「共 6 份」但只列了 3 行 | `content_meta` 是手填的，改配置时别忘了同步 |
| 详情行挤成两行 / 溢出卡片 | 缩短 `content_rows` 里的课件全称；程序会自动降字号到 22px 为止 |
| 「2人拼团」被卡片压住 | `price_dy` 太小。赤金阔幕必须 ≥36（卡片下沿 1572） |
| 打印「违规广告词命中」 | 按提示改对应字段，参考上面的合规替代表 |
| 无码版还是有拼团价 | 检查是不是把 `price_value` 写进了 `only_price`；两版走的是不同分支 |
| 命令行手打路径找不到文件 | 某些目录名里是不换行空格（U+00A0），手打会失效，用 Python 脚本处理 |

## 交付纪律

1. 产物固定 3 件：**2 JPG + 1 PSD**，放进**新建的独立文件夹**。
2. 目录里只留产物 —— 一次性脚本、临时预览图、虚拟环境在完成后**必须清除**。
3. 交付前逐项过一遍 SKILL.md 第七节的自检清单。
4. PSD 图层必须独立可编辑，且背景垫底；合成图必须能被 `sips` 读出尺寸。
