# 中公海报生成器 · zhonggong-poster

> 一段配置 → 两张 **2000 × 2000** 方形高清海报（有码版 / 无码版）+ 一份 **14 图层**可编辑 PSD。
> 全程 Python 出图，**不调用 Photoshop**，不依赖任何外部素材。

`v1.0` · 广东中公教育

---

## 产出长什么样

| 产物 | 内容 |
|---|---|
| `XXX_有二维码.jpg` | 右下留**空白占位框**（虚线描边 + 引导线），框下写「码上获取」；价格同时展示「X人拼团 …元」与「单独购买 …元」 |
| `XXX_无二维码.jpg` | 取消拼团表述，价格改写「**仅售 …元**」为唯一价格，并删除单独购买价 |
| `XXX.psd` | 分层可编辑，14 个独立图层，改字改色不用重跑脚本 |

固定方形 2000×2000，JPG 用 `quality=95, subsampling=0`，印刷与线上投放都够用。

## 特性

- **一次跑出三件套** —— 有码 / 无码 / PSD 同源生成，三份的版式绝对一致，不会出现两版对不齐。
- **纯代码矢量，零外部素材** —— 渐变、径向光晕、圆角卡片、勾选块、虚线框、广州塔线稿、珠江水纹全部由 Pillow + NumPy 程序化绘制，版权干净。
- **文案合规自检** —— 内置 24 条违规广告词黑名单（含「资料」「真题」「押题」「上岸」等），运行时自动扫描全配置并打印命中项，出图前就拦下来。
- **字体白名单硬约束** —— 只从授权字体库按文件名加载，绝不回落到系统字体（PingFang / 微软雅黑一律禁止）。
- **配色整套可换** —— `palette` 是一个完整字典，换项目就换一套撞色（事业单位宝蓝、教师招聘绿黄…），版式骨架不动。
- **地域元素可切** —— `motif` 支持 `canton_tower` / `waves` / `grid`，换地区换元素，避免千篇一律。
- **标题自动两端对齐** —— 给定 `title_width`，程序反算字距让主标题撑满内容框宽度，字号不变，页面更饱满。
- **详情行自适应缩放** —— 课件全称 + 后缀说明一行塞不下时自动从 48px 逐级降到 34px，撑满卡片不溢出。
- **路径零硬编码** —— 输出目录、logo、字体目录全部相对脚本解析，并支持环境变量覆盖，换台电脑直接跑。

## 环境要求

- **Python 3.10+**（实测环境 Python 3.13）
- 依赖五个库：

```bash
pip install -r requirements.txt
```

| 库 | 用途 |
|---|---|
| `pillow` | 画图核心：渐变、圆角、文字排版、图层合成 |
| `numpy` | 背景渐变与径向光晕的像素级计算 |
| `pytoshop` | 写出分层 PSD |
| `psd-tools` | 校验 PSD 图层结构 |
| `six` | pytoshop 的兼容依赖 |

- **授权字体库**（硬依赖）。程序只允许用这一套字体，必须能定位到：

| 用途 | 字体 | 文件名 |
|---|---|---|
| 大标题 / 次级标题（首选） | 方正兰亭粗黑 | `FZLTCHJW.TTF` |
| 大标题备选（加粗宋体） | 方正特雅宋 | `FZTYSJW.ttf` |
| 大标题备选（更重） | 方正兰亭特黑 / 方正粗谭黑 | `FZLTTHJW.TTF` / `FZCTHJW.TTF` |
| 正文 | 方正兰亭黑 | `FZLTHJW.TTF` |
| 备选标题 | 站酷高端黑 / 站酷酷黑 / 庞门正道标题体 | `站酷高端黑修订版1.13.ttf` / `站酷酷黑.ttf` / `庞门正道标题体2.0增强版.ttf` |

默认去 `~/Library/Fonts` 找（macOS）。放在别处就用环境变量指过去：

```bash
export ZG_FONT_DIR="/你放字体的路径/方正字体库"
```

## 快速开始

### 一、出图

**方式一：把素材丢给 AI（推荐）**

把「公告名词 + 课件名称 + 内容 + 拼团价与单独价」四要素发过去，说一句「出海报」。
AI 会改配置 → 出图 → 跑合规自检 → 读图核对版式 → 交 2 JPG + 1 PSD。

**方式二：自己跑**

1. 打开 `poster.py`，改顶部 `CONFIG`（每个字段都有中文注释）：

```python
CONFIG = {
    "base_name": "海珠事编笔试冲刺卷课件包",      # 决定三个产物的文件名
    "project_tag": "事业单位",                    # 右上角项目标签
    "notice": "2026年广州市海珠区事业单位公开招聘高校毕业生公告",   # 公告名词
    "title_main": "海珠事编",
    "title_sub": [["笔试", "w"], ["冲刺卷", "r"]],  # w=白 r=标红
    "content_rows": [
        ["2026海珠区事业单位招聘高校毕业生冲刺卷（一）", "· 参考答案及解析"],
        ...
    ],
    ...
}
```

2. 跑：

```bash
python3 poster.py            # 只出 2 张 JPG
python3 poster.py --psd      # 额外出分层 PSD（推荐）
```

3. 想不改代码、只换一份配置？另存一个 JSON，用 `--config` 覆盖：

```bash
python3 poster.py --psd --config 我的海报.json
```

JSON 里只需写要覆盖的字段（浅合并），其余仍走 `CONFIG` 默认值。

### 二、产物落哪

默认输出到 `<脚本目录>/out/`。想换地方：

```bash
ZG_OUT_DIR="/Users/你/海报成品" python3 poster.py --psd
```

Windows 用 `set ZG_OUT_DIR=...`，PowerShell 用 `$env:ZG_OUT_DIR="..."`。

程序还会往系统临时目录写两张 1000×1000 的预览缩略图（`zg_preview_*.jpg`），方便快速目检，不影响成品目录。

## CONFIG 字段速查

| 字段 | 说明 |
|---|---|
| `out_dir` | 输出目录 |
| `base_name` | 产物文件名前缀 |
| `size` | 画布边长，默认 `2000` |
| `logo_path` | logo 图片路径 |
| `project_tag` | 右上角项目标签（`事业单位` / `教师招聘` / `省考` / `医疗`…） |
| `notice` | 公告名词，标题上方居中浅色小字 |
| `title_main` | 主标题第一行 |
| `title_sub` | 主标题第二行，`[[文本, "w"\|"r"]]`，`w` 白字 `r` 珊瑚橙 |
| `title_main_size` / `title_sub_size` | 两行字号，默认 `238` / `198` |
| `title_width` | 标题两端对齐的目标宽度，默认 `1600`（= 内容卡片宽度） |
| `subtitle` | 亮黄底副标题（如 `全真模拟 · 三套`） |
| `badge` | 青框标签（固定写 `电子课件`） |
| `content_title` | 卡片标题（如 `课件内容`） |
| `content_meta` | 卡片右上角（如 `共 6 份电子文档`） |
| `content_rows` | 详情行 `[[课件全称, 后缀说明]]`，名称左对齐、后缀右对齐 |
| `content_note` | 卡片底部电子版说明，字号 ≥38 |
| `price_group` | 拼团表述（如 `2人拼团`），仅**有码版**显示 |
| `price_value` | 拼团价数字 |
| `price_single` | 单独购买价，仅**有码版**显示 |
| `only_price` | 无码版唯一价格 |
| `only_sub` | 无码版价格下方小字 |
| `claim` | 领取说明 |
| `footer` | 底部低饱和小字，必须含课件全称 |
| `motif` | 地域元素：`canton_tower` / `waves` / `grid` |
| `palette` | 整套撞色字典，可整体替换 |

> **无 kicker 字段**。标题上方的金色小标已永久移除，不要再加回来。

## 九条红线（逐条自检，不可违反）

1. **必带中公教育 logo**。
2. **字体必须在白名单内**，不得使用版权不明的字体。
3. **必须说明课件均为电子版**（「电子课件」标签 + 卡片内文字说明，两处都要）。
4. **底部小字、低饱和度**写明课件**全称**。
5. **全图禁止出现「资料」二字**，一律用「课件」替代。
6. **规避违规广告词**（见下），用同义词替代。
7. **禁用版权不明素材**；需要图形元素时用代码绘制原创矢量。
8. **不调用 Photoshop**，全部在代码层解决。
9. 文案不出现政治 / 医疗等敏感表述；**冲刺卷 ≠ 真题**。

### 违规广告词黑名单

```
资料、真题、押题、上岸、保过、包过、协议班、绝密、内部、命题、
命中、预测、必过、保分、官方指定、第一、最好、最佳、最强、
100%、百分百、泄题、原题、保过班
```

**合规替代**：资料→课件；真题→历年试题；押题→冲刺卷/模拟卷；上岸→成功入围/考入。

脚本每次运行都会扫一遍全配置并打印结果，命中会明确列出是哪个字段的哪句话。

## 设计系统要点

- **扁平化**，禁止阴影 / 浮雕 / 发光堆叠。画面乱、图层不协调基本都是阴影惹的。
- **活力撞色**，主次分明：宝蓝底 + 珊瑚橙 + 亮黄 + 电光青。
  核心标题 / 价格 / 冲刺卷关键字用珊瑚橙，副标题用亮黄底 + 墨蓝字，辅助标签用青。
  ⚠️ **不要用纯正红 `#FF0000` / `#FF3B3B`** —— 在宝蓝底上太刺眼，用珊瑚橙过渡。
- **版式层级（自上而下）**：logo → 项目标签（右上）→ 公告名词 → 主标题两行 →
  副标题 + 电子课件标签（并排居中）→ 课件内容卡片 → 价格区 → 领取说明 → 底部全称小字。
- **大标题必须稳重**：用方正兰亭**粗黑**（B 字重）。不要用特黑 / 超粗，笔画会粘连、字口糊成一团，太粗反而显廉价。
- **地域元素**按项目所在地替换，透明度控制在 0.1–0.25 之间做背景纹理，不与前景争抢。**每次风格必须有区别**。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `FileNotFoundError: assets/logo.png` | 缺 logo。把图放到 `assets/logo.png`，或设 `ZG_LOGO` |
| 报错找不到字体 | 装授权字体库到 `~/Library/Fonts`，或设 `ZG_FONT_DIR` |
| 标题撑出了内容框 | 调小 `title_main_size` / `title_sub_size`，或调大 `title_width` |
| 详情行挤成两行 / 溢出卡片 | 缩短 `content_rows` 里的课件全称；程序会自动降字号到 34px 为止 |
| 卡片说「共 6 份」但只列了 3 行 | `content_meta` 是手填的，改配置时别忘了同步 |
| 打印「违规广告词命中」 | 按提示改对应字段，参考上面的合规替代表 |
| 无码版还是有拼团价 | 检查是不是把 `price_value` 写进了 `only_price`；两版走的是不同分支 |
| 输出的 PSD 打不开 | 确认装了 `pytoshop` 与 `psd-tools`；PSD 用 zip 压缩，PS CS6+ 都能开 |
| 换电脑后路径报错 | 本版已全部改为相对脚本目录解析，正常不会再出现；实在要改就用环境变量 |
| 命令行手打路径找不到文件 | 某些目录名里是不换行空格（U+00A0），手打会失效，用 Python 脚本处理 |
